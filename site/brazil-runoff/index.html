Reproducible, not a black box

Method & provenance

One vote-share scenario

The centre is the weighted Lula share of valid votes. We add any selected pollster corrections and the common shift. Win probabilities are normal-distribution tail areas relative to 50%.

σ² = sampling variance + shared σ² + days left × drift σ²

Reported sample sizes are not effective independent sample sizes. The design-effect assumption inflates sampling variance. If valid n is unavailable, it is estimated from rounded candidate total shares; only if those are unavailable does the model assume 90% of total n. Estimates are marked, not presented as reported respondent counts.

Dependence and scope

Latest wave per pollster is the default. If multiple waves are selected, within-pollster sampling errors are treated as fully correlated. The shared election error remains across all pollsters.

First-round-straddling fieldwork is excluded by default. Strict n > 2,000 excludes a survey with exactly 2,000 respondents. Duplicate releases of one wave are never counted twice.

What is not estimated

No historical calibration, learned house effects, turnout model, campaign-shock model or validation against this election’s outcome. Shifts, design effect, shared error and drift are disclosed assumptions.

Rounding, mode differences and fieldwork timing can matter. A new poll changes the pooled centre and weights; its vote share is not its candidate’s probability of winning.

Source review and update procedure

Update the normalized source ledger, retain original links and fieldwork details, then run the local validation/build script. The page never calls Bloomberg or refreshes polls automatically. Downloaded inputs and the build timestamp make each snapshot reproducible.
